# Solar_Load_Calculator
Automated system to extract electricity bill data and calculate solar requirements using Python and OCR.

## Features
- Local OCR processing (No external APIs used).
- Automated Excel report generation.
- Responsive web interface for bill uploads.

## Tech Stack
- **Backend:** Python (Flask)
- **OCR:** Tesseract OCR
- **Data Handling:** Openpyxl, Regular Expressions (Regex)
- **Frontend:** HTML5, CSS3, JavaScript

## Setup
1. Install Tesseract OCR on your system.
2. Install dependencies: `pip install -r requirements.txt`
3. Run the application: `python app.py`
